# Product Discovery — Phase 1

Baseline product-of-record documents for NurseryVerse AI. All later phases (UX planning, design, architecture, engineering) build against these; changes to scope after this point are change requests against the BRD, not silent drift in a later phase.

1. [Business Requirements Document](01-business-requirements-document.md) — vision, business goals, market/pricing model, scope, risks, roadmap
2. [Software Requirements Specification](02-software-requirements-specification.md) — system-level behavior definition, feature boundaries, interfaces
3. [User Personas](03-user-personas.md) — five personas covering every role in the system
4. [Functional Requirements](04-functional-requirements.md) — FR-1 through FR-20, MoSCoW-prioritized, stable IDs for downstream traceability
5. [Non-Functional Requirements](05-non-functional-requirements.md) — performance, security, availability, compliance, accessibility, and more, written to be testable
6. [User Stories](06-user-stories.md) — persona-driven stories with acceptance criteria, traced to Functional Requirements
